How long can I store data?

SQLite can store years of data with no issues. At typical usage (50 orders/day), the database stays under 50 MB per year. The auto-archive only triggers above 400 MB — roughly 10+ years of data.

archive
What happens when data is archived?

Your old database is never deleted. It gets copied to HotelManager\archives\ with a date stamp. The app then starts a fresh database. You can open the archive file any time using DB Browser for SQLite (free tool).
